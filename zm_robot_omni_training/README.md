# zm_robot_omni_training

Isaac Lab training code for `zm_robot_omni_policy` (the ROS 2 package next to this folder): the
goal-reaching environment for zm_robot, SAC training (LiDAR-only and X-Mobility + residual),
evaluation, export to ONNX, and the scripts behind the paper figures and comparison videos.

This is **not a ROS 2 package**. `COLCON_IGNORE` keeps colcon from scanning it.

Copied on 2026-11-17 from `~/nvidia/zm_robot_omni_training`, keeping only the code. The original
folder is unchanged and still holds the training logs and checkpoints.

## Layout

| Path | Contents |
| --- | --- |
| `train_sac.py` | SAC training (Stable-Baselines3): `--obs state_lidar` or `state_lidar_xmob`, `--reward progress/penalty/hybrid`, `--residual_scale` |
| `train.py` | earlier RSL-RL PPO training (superseded by SAC; kept for reference) |
| `zm_robot_omni_training/config/` | environment, scene, robot and agent configurations |
| `zm_robot_omni_training/mdp/` | actions, observations, rewards, terminations, commands, events |
| `zm_robot_omni_training/wrapper/` | environment wrapper (collision checker) and residual-action wrapper |
| `zm_robot_omni_training/models/xmobility.py` | frozen X-Mobility runner |
| `zm_robot_omni_training/third_party/x_mobility/` | vendored X-Mobility model code and gin config |
| `zm_robot_omni_training/usd/` | zm_robot and office scene USD (with the occupancy map) |
| `scripts/` | evaluation, export, recording and the experiment drivers (`run_*.sh`) |
| `paper/` | figure, statistics and video scripts; `paper/data/` holds the extracted results they read |

## Running

The container used for training is gone. Scripts now run on the Isaac Lab in the IsaacLab-Arena
virtual environment, with the extra packages in `.pydeps/`:

```bash
cd ~/catkin_ws/src/zm_robot/zm_robot_omni_training
uv pip install --python ~/nvidia/IsaacLab-Arena/.venv/bin/python --target .pydeps --no-deps -r requirements-extra.txt
```

```bash
PYTHONPATH=$PWD:$PWD/.pydeps HF_HUB_OFFLINE=1 OMNI_KIT_ACCEPT_EULA=YES ~/nvidia/IsaacLab-Arena/.venv/bin/python scripts/record_clip.py --help
```

Only `scripts/record_clip.py` (and `scripts/run_grid_clips.sh`) has been run on that newer Isaac
Lab; it carries two small compatibility shims at the top. `train_sac.py`, `scripts/eval_sac.py`
and the other scripts were written for the old container and have **not** been run on it; expect
to port the same shims (and the `--headless` / `--enable_cameras` flags, which the newer
AppLauncher no longer accepts) before training again. The `run_*.sh` experiment drivers call
`python3`, which inside the old container was Isaac Lab's Python.

Scripts read checkpoints from `logs/sb3/...` relative to this folder; point `--checkpoint` at
`~/nvidia/zm_robot_omni_training/logs/...` or `~/nvidia/zm_robot_omni_training/deploy_models/checkpoints/`.
